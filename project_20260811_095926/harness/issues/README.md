# 问题管理规则

`ISSUE_REGISTER.md` 是所有已知问题的动态真相源。

## 状态

- `Open`：已确认但尚未开始。
- `In Progress`：当前正在处理。
- `Blocked`：无法继续，必须写明阻塞条件和解除方式。
- `Deferred`：确认存在但不在本期，必须保留后续进入条件。
- `Resolved`：已完成且有验证证据。
- `Won't Fix`：明确决定不修，必须引用决策编号。

## 规则

1. 问题不得删除或静默合并。
2. 新发现必须分配稳定ID。
3. 每个实现批次结束时更新状态和最后检查日期。
4. `Resolved` 必须包含提交、测试或可复现验证证据。
5. `Blocked` 和 `Deferred` 必须说明原因、风险和下一步。
6. 当前迭代完成时仍未解决的问题继续保留，不得因发布而清空。
