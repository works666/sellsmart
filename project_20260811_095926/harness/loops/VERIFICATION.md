# 验证循环

## 文档与治理修改

- 运行 `scripts/harness-check.ps1`。
- 检查 Git diff 和工作树状态。

## 普通前端修改

- TypeScript 检查。
- ESLint。
- 相关页面交互冒烟。
- 检查加载、空数据、错误和刷新状态。

## API与数据修改

- 请求/响应契约测试。
- 鉴权与越权测试。
- 成功、校验失败、依赖失败和超时路径。
- 数据迁移与回滚检查。

## AI修改

- 固定输入回归样例。
- JSON结构校验与非JSON回退。
- NPC身份隔离、上下文隔离和提示词注入检查。
- Token窗口、超时、重试、流中断和成本记录。
- 关键分数与解锁不能只依赖未校验自然语言。

## 游戏状态机修改

- 正常完成、提前结束、失败、刷新恢复和重复请求。
- 轮次、操作点、亲密度、线索和结果的状态不变量。
- 服务端与页面显示一致。

## 发布门

- 构建通过。
- P0/P1验收完成。
- 无真实密钥进入 Git。
- 迁移、环境变量、监控和回滚说明齐全。
