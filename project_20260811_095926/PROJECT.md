# 项目章程

## 产品目标

建设一套面向政企/B2B 销售人员的 AI 竞标实训平台。玩家通过项目选择、NPC 对话、线索挖掘、关系经营、竞品博弈和结算复盘完成销售训练；平台同时支持设计师、企业管理员和培训教练角色。

## 当前阶段

项目已进入开发与验证阶段：旧项目一持久化单机/联机闭环和五人AI预览并存。当前批次维护已有功能缺陷；五人正式持久化迁移、后台与实时联机仍需后续实施，具体能力和证据以 harness/STATE.md 为准。

## 当前目标

执行 harness/plans/CURRENT_ITERATION.md 中已批准的工作。2026-09-08用户限定本批先修已有功能缺陷，并授权C0采用合理修正版；其余大型未完功能不纳入本批。

## 建议的产品北极星

优先交付一个可重复验证的“项目一单人闭环”：创建对局、独立 NPC 会话、轮次与操作点、线索解锁、规则结算、AI 复盘和历史保存全部贯通。

该建议不是已批准的本期范围，最终以 `harness/plans/CURRENT_ITERATION.md` 中的批准清单为准。

## 边界

- `projects/` 是应用工程，不在范围确认前进行业务修改。
- 外部素材库是输入资料，不等同于已批准需求。
- 任何冲突规则必须进入决策日志，不能由开发者静默选择。
- 密钥和环境变量不得提交 Git。
- 每一项实现必须有来源、验收条件和验证记录。
