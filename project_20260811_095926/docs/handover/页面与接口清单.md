# 页面与 API 清单

基于 2026-10-30 `projects/src/app/` 下 27 个 `page.tsx`、54 个 `route.ts` 文件。动态路径使用 `[id]`。接口的实际权限和数据副作用以各自 Route Handler 中的权限校验、输入 schema 和仓储为准；本清单只用于导航，不替代 API 契约。

## 页面

| 页面 | 用途 / 当前状态 |
|---|---|
| `/` | SellSmart 产品入口/落地页。 |
| `/about` | 产品介绍页。 |
| `/login` | 演示登录和角色选择；并未接真实短信、账号密码或受信身份供应商。 |
| `/home` | 登录后工作台/项目入口。 |
| `/start` | 项目和单局模式选择；项目一是当前正式开放项目入口。 |
| `/game` | 正式项目一游戏工作台及对局状态、聊天、时间、行动与任务交互。 |
| `/result` | 项目结果和训练复盘、能力维度与对话/证据概览。 |
| `/ranking` | 排行榜页面。 |
| `/room` | 旧房间实时看板入口。页面代码明确显示“暂未开放”。 |
| `/coach` | 培训教练多人房间管理；断线监测、实时广播/自动同步仍有缺口。 |
| `/enterprise-admin` | 企业管理 UI；部分玩家、场景、邀请码、发起对局、报告/定制等仍显示空态或禁用态。 |
| `/setup` | 身份/玩家工作区设置页。 |
| `/knowledge` | 知识库页面；上传当前是演示交互，代码提示未来才接上传 API 和对象存储。 |
| `/project-one-preview` | 五人版交互/AI 预览，载入 `public/project1-prototype-v9.html`。不写正式玩家 `/game` 存档。 |
| `/designer` | 设计师主工作区；素材/场景等编辑入口。 |
| `/designer/ai-provider` | 命名 AI Provider 选择与配置界面。 |
| `/designer/client-info` | 客户信息工作台/编辑界面。 |
| `/designer/customer-activities` | 客户活动匹配规则与门槛配置。当前规则涵盖四种活动；配置读写受身份和 revision 控制。 |
| `/designer/data-import-export` | Excel 数据模板下载、上传、校验和预览。解析不会自动持久化业务配置。 |
| `/designer/dialogue-prompts` | DeepSeek/豆包双轨提示词对话测试、重置及 PDF 导出。 |
| `/designer/eval-prompts` | Evaluator/评价提示词工作台。 |
| `/designer/formulas` | 指标/公式编辑与校验工具。 |
| `/designer/jev-config` | Jev 结构化决策配置。 |
| `/designer/key-persons` | 项目一五人关键人物档案及配套 Excel 导入导出入口。 |
| `/designer/metrics` | 项目指标数据和公式查看/编辑。 |
| `/designer/prompt-library` | 提示词库与人物角色/渠道配置。 |
| `/designer/system-evaluation` | 五人预览同业务链路的隔离系统评测、评分报告和 JSON 导出。 |

## API

### 登录、通用对话和状态

| 方法 | 路径 | 说明 |
|---|---|---|
| `POST` | `/api/auth/login` | 演示登录、发验证码响应和选择角色；不要作为生产身份验证。 |
| `POST` | `/api/chat/stream` | 正式聊天/流式回复入口。 |
| `GET` | `/api/health/startup` | 启动、构建号和数据库健康检查。 |
| `GET` | `/api/ranking` | 排行榜查询。 |
| `POST` | `/api/scenario/generate` | AI/规则生成场景。 |
| `GET` | `/api/testing/fast-debug` | 快速测试观测接口；受测试环境/开关约束。 |

## 数据流简图

```text
浏览器页面
  ├─正式玩家 /game ────────── /api/game/sessions、/chat/stream
  │                              └─游戏规则 + AI Provider + Supabase/Drizzle
  ├─五人预览 /project-one-preview ─ /api/project-one-preview/ai
  │                                      └─隔离预览会话/命令记录
  ├─设计师 /designer/* ───────── /api/designer/*
  │                                  └─设计配置表 + Supabase Storage
  └─教练/企业页面 ──────────── /api/coach/*、/api/enterprise/*
                                         └─实现状态以页面/接口/问题台账复核
```

页面存在不代表其后端功能已完整。尤其是 `/knowledge` 上传、真实短信登录、企业认证/归属、报告管理和实时多人广播，应按源码和当前问题台账判定，不从页面外观推断已接通。
