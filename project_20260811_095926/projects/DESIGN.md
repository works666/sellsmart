# 企业风

## 类型
B2B 后台、企业平台、运营管理、财务系统。

## 设计关键词
安静、可信、低噪音、高信息密度、专业克制。

## 色彩
- 背景：#F6F8FB
- 卡片：#FFFFFF
- 主文本：#152033
- 次文本：#637089
- 品牌蓝：#2F6BFF
- 成功绿：#16A37B
- 分割线：#E6EAF2

## 字体
优先使用 Inter、IBM Plex Sans、系统无衬线。数字使用等宽特征更佳。

## 布局
左侧可扩展导航，顶部状态栏，主区域使用清晰卡片和表格。间距充足但不浪费空间。

## 组件
- 顶部筛选栏
- 指标卡片
- 表格
- 状态徽标
- 轻量图表

## 动效
仅在 hover、展开、切换时使用短动效。不要影响效率。

## 禁忌
不要过度渐变，不要大量插画，不要把企业后台做成营销页。

## 增量规范（v2 · 多身份权限 + 场景生成 + 排行榜 + 多人房间）

### 新增色彩（角色/状态标识）
- 平台设计师色：#7C3AED（紫）
- 企业管理员色：#0EA5E9（青）
- 培训教练色：#EA580C（橙）
- 玩家色：品牌蓝 #2F6BFF
- 排名奖牌：#FFD700（金）/ #C0C0C0（银）/ #CD7F32（铜）
- 警告色：#EA580C（橙红，用于强制结束/危险操作）

### 新增组件
- 4 身份选择卡：200x260 卡片，悬停抬升 4px + 边框变蓝
- 二级身份 Tab（玩家内嵌）：企业员工/付费个人 互斥胶囊
- 排行榜表格：行高 56px，前 3 名金色渐变背景 + Trophy + 顶部 0.5 横条
- "我"行高亮：蓝色背景 + 左侧蓝条
- 等级徽标 Lv.1-3 灰 / Lv.4-6 蓝 / Lv.7-9 紫 / Lv.10 金
- FAB 浮动按钮：右下 44x44 蓝色圆形
- 房间号大字号：等宽字体 + Copy 图标
- 圆形倒计时：进度条 + 数字（蓝→绿→红渐变）
- AI 场景生成器：左侧"生成参数"（下拉+自定义输入+AI 按钮）+ 右侧"生成结果"（可编辑表单）
- 加载态：行内 spinner（蓝色 2px 圆环旋转）

### 布局
- 多人房间：左侧玩家列表面板（288px） + 中间动态时间线（自适应） + 右侧教练管控工具（288px）
- 玩家视图：左侧共享项目场景（320px） + 中间自己的对局操作 + 右侧队友实时排名
- 排行榜：4 列指标卡 + Tab 切换（房间榜/全平台榜）+ 表格 + 底部汇总 + FAB

### 身份权限视觉表达
- 顶部右上角身份切换胶囊：当前身份 + 切换按钮
- 不同身份页面背景色微调（设计师偏紫/管理员偏青/教练偏橙/玩家保持原蓝）

### 动效补充
- 身份选择弹窗：淡入 + 缩放（180ms）
- 玩家卡片悬停：抬升 4px + 阴影增强 + 边框变蓝
- 倒计时：每秒 1 次脉冲（仅最后 60s 触发）
- 排行榜 Tab 切换：下划线滑动（200ms）

### 落地约束
- 早期前端原型仅实现 UI + 模拟交互；当前 AI 调用与数据持久化已迁移到应用服务端和 Supabase
- 数据表：用户身份表/企业信息表/邀请码记录表/行业分类表/产品分类表/标准场景案例表
- 工作流：身份权限判断工作流 / 多人房间教练管控工作流（保留原有 3 条）
- UI 素材以人工上传为准，AI 不自动生成页面图片素材
- 批量导出/复杂统计功能预留后端接口
